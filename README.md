# InvCount

InvCount è un gestionale per inventari nei punti vendita: preparazione
dell'inventario, conteggio degli articoli da smartphone, confronto con le
giacenze teoriche e report finale per il cliente.

Lavoro come team leader negli inventari retail e sto costruendo da zero il
software che supporta questo lavoro, per imparare come si progetta un sistema
gestionale reale. Il progetto è impostato come un tirocinio, con ticket,
code review e un diario di bordo.

## Tecnologie
- Java 21, Spring Boot
- PostgreSQL
- HTML/CSS/JavaScript, poi Angular

## Stato
In sviluppo — fase 0: preparazione dell'ambiente e struttura del progetto.
